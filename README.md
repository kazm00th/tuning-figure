# 鍵盤楽器の為の十二音相環図

公開ツール：https://kazm00th.github.io/tuning-figure/

独自コードは[MIT License](LICENSE)。参照元と生成図に関する適用範囲は[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)を参照してください。

`index.html` をブラウザーで開くと動きます。インストール、ビルド、通信、ローカルサーバーは不要です。

- Cは0 cent固定。残りの11音はCからの音程を入力します（平均律なら100, 200, …, 1100）。
- 入力のたびにSVGを更新します。小数に対応します。
- プリセットは平均律、Kirnberger I、Bach WTC / Jobin、Meantone、Base of Bach WTC、VeryWell 2.0、Praetorius、Bach / Kellnerに加え、参照ページから追加した14例の計22種類。選択すると全音の値と図が即座に切り替わります。選択後の手動編集も可能です。
- 「SVGを保存」で図を保存できます。
- 「PNGを保存」で図をPNG画像として保存できます。倍率は1〜4倍（1倍は764×794画素、既定は2倍）。文字は画面と同じく見る人の環境の書体で描かれます。PNGにはiTXtチャンク（UTF-8）で、図の題名（Title）、作成ソフト（Software）、SVGのmetadataと同じJSON（キーワード tuning-figure）を入れます。
- 図の楕円や扇形をクリックすると和音が鳴ります。「クリックで鳴らす」のスイッチで切り替えます（最初は二音）。二音：楕円は根音と長三度、扇形は根音と五度。三和音：楕円・扇形のどちらでも根音・長三度・五度。音の高さはC4＝261.63 Hzを基準に、根音はC4〜B4（入力したCからのcent）、長三度・五度は図と同じ音程で根音の上に重ねます。音色はのこぎり波を模した16倍音までの正弦波合成（振幅1/n）。同時に鳴らし、10 msで立ち上がって指数関数的に減衰し、3秒で−60 dBになって止まります。鳴っているうちに次を押すと、前の音は10 msで止めます。音量は固定（1音0.2）。中央の円と音名では鳴りません。保存するSVG・PNGは変わりません。
- 再読み込みすると平均律に戻ります。入力値の自動保存機能はありません。
- 数値はCから昇順、1200 cent未満で入力します。空欄や作図範囲外の間は直前の図を残し、理由を表示します。その間はSVG・PNGの保存を無効にします。

## 作図の定義

参照: 岡本芳雄「鍵盤楽器の為の十二音相環図」

- https://pianotuning.jp/?page_id=236 （作図の方法）
- https://pianotuning.jp/?page_id=215 （Kirnberger I）

参照図の画像は同梱せず、各入力値から新規のSVG図形を生成します。長三度はCIE LCh（D50）、完全五度はCIE Lab（D50）の近似式で、どちらも掲載主図25枚（24ページ）の楕円・扇形の色をセント値ごとに平均した値に当てはめています（色見本ページ1027・3956は参考）。元画像ごとの色差があるため完全な複製ではありません。

半音順の各入力を p[i] とし、五度は7半音先、長三度は4半音先との差を計算します。添字が12を越えるときだけ1200を加えます。

五度Fの扇形角は `30 + (F - 700) * (30 / 700 * 10)` 度。Dを真下に置き、D A E B F# C# Ab Eb Bb F C Gの順に反時計回りで配置します。Dの位置は図の回転を固定するだけで、入力値をD基準に書き換えません。12五度の合計は8400 cent、扇形角の合計は360度です。

外周半径R、長三度Mに対する内端rは以下です。

```
q = (1 - sin(15°)) / (1 + sin(15°))
r = R * (0.5 - (M - 400) * (q - 0.5) / (400 - 386))
楕円の中心距離 d = (R + r) / 2
半径方向の半軸 a = (R - r) / 2
接線方向の半軸 b = tan(扇形角 / 2) * sqrt(R * r)
```

これにより30度の扇形でM=386は内接する真円、M=400は内端が半径1/2の楕円になります。外周への接触に加え、両放射線への接触も満たします。元の作図法（ページ236）と同じく、真円にする純正長三度は整数の386 centで、400と386の同心円の間を14等分して1 centの目盛りにします。

拡大した角度が0–180度の開区間外、rが0–Rの開区間外、またはb²>aRで楕円が外周を越える入力は、元の作図法の幾何が成立しないため拒否します。値を黙って丸めたり図だけを切り詰めたりしません。

図の括弧内の基準と真円の基準は、参照方法の整数値702・386 centです。厳密な比3:2、5:4の値は約701.955、386.314 centで、これらは入力値どおりに描きます（5:4は真円よりわずかに縦長）。音程計算は入力精度を保持し、表示時だけ丸めます。

Kirnberger Iは参照図の丸め値に対応した `0,90,204,294,386,498,590,702,792,884,996,1088`。D–Aが680、F#–C#が700、他の五度が702 centとなります。

## 周波数比で入力する

入力欄の上のスイッチで「cent」と「周波数比」を切り替えられます。周波数比のモードでは、各音の C からの周波数比を1行の式で書きます（1以上2未満）。式は素数ごとの分数の指数（∏ p^(n/m)）に直して誤差なく持ち、図を描く直前に一度だけ cent に直します。欄の下には、素数の小さい順に並べた正規化した形と cent を表示します（例：`10^(7/8)/5` → `= 2^(7/8)·5^(−1/8)　701.711 cent`）。

| 書き方 | 意味 | 例 |
|---|---|---|
| 整数、`a/b`、`a*b` | 割る・掛ける（左から順に） | `5/4`、`3*2^(-7/6)` |
| `^整数`、`^(p/q)` | べき乗（直前の数・括弧・√ に掛かる。1回まで） | `3^-1`、`5^(1/4)`、`2^(13/6)/3` |
| `√x`、`sqrt(x)`、`√[n]x` | 平方根・n 乗根（すぐ後ろの数か括弧に掛かる） | `√5/2`、`√[4]5` |

空白・全角の数字と記号・`·`・`×`・`÷`・`−` も使えます。小数・省略した掛け算（`2√5`）・べきの連続（`2^3^2`）・0・負の数は使えません。式は 200 文字、入れ子は 50 段、整数は 10^12 までです。範囲の外の比はエラーになり、「オクターブを合わせる」で 2 のべきを掛けて直せます。

切り替えると各欄を変換します（cent → `2^(c/1200)`、比 → cent）。cent から比へは、指数の分子・分母が 10^12 に収まるいちばん長い桁数に四捨五入します。そのため往復すると値が 10^-8 cent ほど動くことがありますが、すべての音がプリセットから 10^-6 cent 以内なら、そのプリセットとして題名を出します。周波数比のモードでプリセットを選ぶと、その音律の定義から作った厳密な比が入ります。16個（平均律、Kirnberger I・III、Jobin、Meantone、Base of Bach、VeryWell 2.0、Praetorius、Kellner、Bach / Seal、Werckmeister III、Valloti、Young II、Pythagoras、Lehman、Schnitger）は純正五度とコンマ（シントニック・ピタゴラス・スキスマ）の分数で定義され、掲載図の丸めた値とは各音で最大 0.63 cent 違います（Meantone の G♯ = 25/16 など）。VeryWell 2.0 は 702 を純正五度、700 を平均律の五度と読みます。Bach's Seal 1.5・1.0、Meantone / forPiano698、Bach WTC forPiano、VeryWell 1.0・3.0 は作者が cent で定めた調律法なので `2^(c/1200)` です。

## 色と楕円の更新

完全五度の式（v2、cはcent、Lab白色点はD50）:

```
c <= 680: L*=a*=b*=0
680 < c <= 702: L*=100*(1-((702-c)/22)^1.12514), a*=b*=0
702 < c: d=min(c,738.5)-702
L*=96.6412 - 1.23208*d - 0.00578128*d²
C*=6.47272*d^0.215202 + 0.0142881*d²
h=348.628°（一定）、a*=C*cos(h)、b*=C*sin(h)
```

702 centは白です。その直後、L*は96.6へ不連続に下がり、C*は0から急に立ち上がります（702.1 centで3.94、705.5 centで8.65。掲載図は702.1で3.9、705.5で9.9）。C*の式は、702〜705.5 centの急な立ち上がりを2次式では追えなかったため、べき乗と2次の和にしました（掲載主図の10点で、2次式よりAICc・BIC・AICが4.9良く、RMSEは1.31から1.03）。680〜696 centには掲載図のデータが無く、この区間はほぼ直線でつないでいます。ピンクの色相は掲載図の揺れ（343〜356°）の中で一定と見なしました。LabからXYZ(D50)、Bradford順応でXYZ(D65)、線形RGB、sRGBへ変換します。738.5 cent超は未検証の外挿を避け、738.5の色に固定します。SVG保存も同じ配色を使い、metadataに式の識別子と適用範囲を記録します。

線（図の幅850、外周半径315の単位）: 扇形の輪郭は#808080・太さ1、平均律位置の破線は#888888・太さ1・破線2 3（周期5）、外周円は#778975・太さ1。扇形の輪郭と破線は、ページ32・496・691・2295の掲載図と同じ縮尺にそろえ、線を横切る濃度の断面で地の色からの暗さと破線の周期を測って合わせました。掲載図の線は1ピクセル前後のため、色と太さは分離せず、両者の組で暗さを合わせています。

中央の円は半径53、塗り#f7b779、縁#7a6450・太さ1で、中に文字は入れません。掲載図6例（ページ135・215・496・691・2284・2295）で半径・塗り・縁の暗さを測って合わせました。五度の数字は文字の大きさ11の2行で、1行目の基線を半径70、2行目を81に置きます（掲載図5例の扇形中央での文字の位置に合わせた値）。狭い扇形で数字が扇形の両辺からはみ出す場合は、実際に描かれる字の範囲（CanvasのmeasureText）で測り、両辺から1.5の余白を残して収まるまで2行とも同じ比率で縮めます（基線の位置は変えません）。五度の数字には文字と同じ色の太さ0.1の輪郭を付け（輪郭を先に描く）、線を少し太らせています。プリセットのある18枚の五度の数字216個で、元図と同じ解像度にそろえて文字のインクの量を比べ、輪郭なしでは元図の0.81〜0.92倍だったものを、白地・灰色地で1.03〜1.05倍に合わせました（700 cent前後の明るい灰色の地では0.91倍）。

長三度の数字は、楕円の大きさによらず内端から一定の位置に置きます（基線は内端から24.5と38.5、文字の大きさ14と12）。数字の書体はMeiryo UI（無い環境ではMeiryo、system-uiの順に代替）。暗い文字は黒で描きますが、白文字との選択は従来どおり#26352bとのコントラストで判定し、掲載図で白文字の404〜406 centの楕円が黒文字に変わらないようにしています。楕円の輪郭は#353535・不透明度0.85・太さ0.9、平均律位置の破線は外周から20まで伸ばします。図の範囲はviewBox「43 28 764 794」で、外周の半径に対する幅2.43倍・高さ2.52倍という掲載図の余白に合わせています。これらは掲載図7例（ページ32・39・215・496・691・2284・2295）で、楕円の内端と扇形中央に沿った断面を測って合わせました。

音名は掲載主図25枚のうち17枚が使う表記（2012〜2014年の図など）にそろえ、プリセットにも任意の入力にも同じ表記を使います。外周（扇形の境界）はD G C F ♭B ♭E ♭A B E Aと、2段の「♯C／♭D」「♯F／♭G」（外周円に近い側が♯）。長三度（扇形の中央、外周円のすぐ外）は鍵盤上の名前の小文字で、♯f b e a d g c f ♯a／♭b ♯d ♯g ♯cです（G♯の三度もcと書き、hisとは書きません）。変化記号は掲載図どおり音名の前に置きます。文字は扇形と一緒に回転し（文字の上が中心を向く）、幹音は灰色の袋文字（#666666の輪郭）、変化音は黒（#222222）の塗り文字です。外周は文字の大きさ26.5・基線は外周＋27.3・2段目は＋21.8、長三度は大きさ21・基線は外周＋18.3・2段目は＋17で、♯・♭は文字の0.8倍（長三度は0.85倍）にして音名に寄せます。ページ20・32・39・42・135・215・496・2153・2306・4362の10例で、各音名を正立させる向きの断面から字の範囲と濃さを測って合わせました。ドイツ語の音名の図（ページ1545・1783・2284・2295・2680）や、黒鍵の名前を図ごとに変えた図（ページ691・3448・4026）の表記は再現しません。

同心円は380〜428 centの1 centごとで、色は長三度の楕円と同じ式（thirdColor）です。太さと不透明度は、408 cent超が0.6・0.45、400〜408 centが0.6・0.9、400 cent未満が0.8・0.9。400 centとピタゴラス長三度の408 centは太さ1.8・不透明度0.6で強調します。範囲（掲載図では428 centから始まる）・帯ごとの平均の色・400／408 centの円の濃さは、ページ215・691・2284の純正長三度の扇形に沿った中心からの断面で合わせました。真円が接する386 centの円も太さ1.8・不透明度0.5で強調します（元の作図法で黄に塗る円）。

真円校正は五度700 centかつ長三度386 cent（元の作図法と同じく整数値。厳密な5:4ではありません）。半径R=1のとき、386 centの半軸はa=b=0.205604647。厳密な純正長三度1200 log2(5/4)=386.313713865 centはa=0.206599464、b=0.205256965（軸比1.00654のわずかに縦長の楕円）。平均律400 centはa=0.25、b=0.189468691（軸比1.31948）。ピタゴラス長三度1200 log2(81/64)=407.820003462 centはa=0.274797987、b=0.179826456（軸比1.52813）。aは半径方向、bは接線方向です。掲載図17枚の楕円203個の内端を測ると、ツールとの差は長三度に比例し（傾き0.000171 R/cent、標準誤差0.000012）、この目盛り（1 centは400と386の差の1/14）から予想される0.000145と合います。

長三度の式（v2）: P=1200 log2(5/4)（純正）、K=1200 log2(81/64)（ピタゴラス）。L*・C*は384 centの値から386 centの実測の最大値（L* 94.908、C* 75.018）まで直線で上がり、Pまで同じ値を保ちます（掲載図は純正長三度を386と書いて同じ色で塗るため）。Pより右は次のとおりで、全係数はpalette.jsのTL・TC・THにあります。

```
gg(x; B, μ, w, β) = B·exp(−|(x − μ)/w|^β)            （一般化ガウス形のこぶ）
L*: P〜K   94.908 − 2.21891·d − 0.00905494·d² + こぶ    （d = c − P）
    K超    28.7861 + 14.2134·exp(−(c − K)/5.4491) + こぶ （Kで値・傾きが連続）
    こぶ   gg(c; 1.83248, 405.822, 4.74112, 5.5405)
C*: 24.8346 + A·S(c) + gg(c; 20.5711, 400, 4.21333, 1.40969) − 1.92342·exp(−((c − 397.529)/0.896246)²)
    S(c) = 1/(1 + exp((c − 392.105)/5.12389))、AはPでC*=75.018となる値（66.251）
h:  91.3905 + 148.082/(1 + exp(−0.211737·(c − 400.865))) + gg(c; −11.4279, 403.823, 4.15327, 3.03524)  （384〜428全域）
```

C*の397 cent付近のくぼみは、谷底（397.34 cent）が掲載図のデータの無い397〜398 centの間に来ますが、その付近の掲載図の最小値（397.0 centの平均52.7246）を下回らないよう制約して当てはめています（谷底の値がちょうどこの最小値）。

400 cent以上はL*・C*が単調非増加、hが単調増加です。Labへの変換はa*=C*cos(h)、b*=C*sin(h)（角度をラジアンに変換）。sRGB色域外はRGB成分を0〜1にクリップ。SVGも同じ配色式を使用。長三度384〜428、五度680〜738.5の外側は端の色で固定します。

色の根拠は掲載主図25枚（プリセットのある18枚と、ページ36・45・100・598・1545（Lehman）・3462・3717の7枚）で、楕円の内側と扇形の外周近くの色を測り、セント値ごとに平均して当てはめました（長三度55点、五度26点）。式の形はAICc・BIC・AIC・1点抜き交差検証で比べて選んでいます。390・392 centは色見本ページ1027と主図で色が異なり（ΔE約5）、主図を採りました。Bach/Kellner・Bach/Sealの403.1〜403.2 cent、Base of Bachの402.5・411.5 centは他の掲載図と色が合わないため当てはめから外しており、これらのプリセットの該当する楕円は元図とΔE 3〜6異なります。長三度の残りの誤差（L* 0.30、C* 0.29、h 0.79）は主に色の表の段差によるもので、同じセント値の測定どうしの揺れ（0.2〜0.3）より大きい分は滑らかな式では追えません。
