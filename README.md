# 鍵盤楽器の為の十二音相環図

公開ツール：https://kazm00th.github.io/tuning-figure/

独自コードは[MIT License](LICENSE)。参照元と生成図に関する適用範囲は[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)を参照してください。

`index.html` をブラウザーで開くと動きます。インストール、ビルド、通信、ローカルサーバーは不要です。

- Cは0 cent固定。残りの11音はCからの音程を入力します（平均律なら100, 200, …, 1100）。
- 入力のたびにSVGを更新します。小数に対応します。
- プリセットは平均律、Kirnberger I、Bach WTC / Jobin、Meantone、Base of Bach WTC、VeryWell 2.0、Praetorius、Bach / Kellnerに加え、参照ページから追加した10例の計18種類。選択すると全音の値と図が即座に切り替わります。選択後の手動編集も可能です。
- 「SVGを保存」で図を保存できます。
- 再読み込みすると平均律に戻ります。入力値の自動保存機能はありません。
- 数値はCから昇順、1200 cent未満で入力します。空欄や作図範囲外の間は直前の図を残し、理由を表示します。その間はSVG保存を無効にします。

## ファイル

- index.html: 画面、CSS、説明
- tuning.js: 音程計算と幾何計算（ブラウザーとNode.jsで共用）
- palette.js: 基準ページの色と補間、文字のコントラスト
- app.js: 入力、SVG描画、表、SVG保存
- tests/tuning.test.js: 計算の検証

## 作図の定義

参照: 岡本芳雄「鍵盤楽器の為の十二音相環図」

- https://pianotuning.jp/?page_id=236 （作図の方法）
- https://pianotuning.jp/?page_id=215 （Kirnberger I）

参照図の画像は同梱せず、各入力値から新規のSVG図形を生成します。長三度は基準ページ1027と20参照ページの全255点に基づくCIE LCh（D50）の近似式、完全五度は基準ページ3956をもとにしたCIE Lab（D50）の近似式です。元画像ごとの色差があるため完全な複製ではありません。

半音順の各入力を p[i] とし、五度は7半音先、長三度は4半音先との差を計算します。添字が12を越えるときだけ1200を加えます。

五度Fの扇形角は `30 + (F - 700) * (30 / 700 * 10)` 度。Dを真下に置き、D A E B F# C# Ab Eb Bb F C Gの順に反時計回りで配置します。Dの位置は図の回転を固定するだけで、入力値をD基準に書き換えません。12五度の合計は8400 cent、扇形角の合計は360度です。

外周半径R、長三度Mに対する内端rは以下です。

```
P = 1200 * log2(5/4)
q = (1 - sin(15°)) / (1 + sin(15°))
r = R * (0.5 - (M - 400) * (q - 0.5) / (400 - P))
楕円の中心距離 d = (R + r) / 2
半径方向の半軸 a = (R - r) / 2
接線方向の半軸 b = tan(扇形角 / 2) * sqrt(R * r)
```

これにより30度の扇形でM=P（約386.313713865）は内接する真円、M=400は内端が半径1/2の楕円になります。外周への接触に加え、両放射線への接触も満たします。

拡大した角度が0–180度の開区間外、rが0–Rの開区間外、またはb²>aRで楕円が外周を越える入力は、元の作図法の幾何が成立しないため拒否します。値を黙って丸めたり図だけを切り詰めたりしません。

図の括弧内の基準は参照方法の整数値702・386 centです。厳密な比3:2、5:4の値は約701.955、386.314 centであり、両者を混同しません。音程計算は入力精度を保持し、表示時だけ丸めます。

Kirnberger I例は参照図の丸め値に対応した `0,90,204,294,386,498,590,702,792,884,996,1088`。D–Aが680、F#–C#が700、他の五度が702 centとなります。

## 検証

追加プリセットは各ページの丸めた基準（狭い五度696.5、純正五度702 cent）からC=0に換算した値です。

- Jobin: https://pianotuning.jp/?page_id=1545 。残り3個の五度は703+1/6 centとして一周を閉じます。掲載値703.1と一致せず、厳密な周波数比によるJobin音律とも区別します。入力欄の循環小数を途中で丸めず保持しています。
- Meantone: https://pianotuning.jp/?page_id=691 。五度696.5が11個、G♯–E♭が738.5 cent。386の長三度が8個、428が4個です。二重黒鍵の図と半音階図は対象外です。
- Base of Bach WTC: https://pianotuning.jp/?page_id=2680 。五度696.5が5個、702が6個、G♯–E♭が705.5 cent。元ページの筆者による仮説的な調律案です。

Node.jsがある場合:

追加の3例も、下記の掲載図にある五度12個・長三度12個と照合済みです。厳密な周波数比からの再計算ではなく、図のcent表示を再現しています。

- VeryWell 2.0: https://pianotuning.jp/?page_id=42 。五度698・700・702 centが4個ずつ。
- Praetorius: https://pianotuning.jp/?page_id=2284 。五度696.5が9個、702が2個、727.5が1個。
- Bach / Kellner: https://pianotuning.jp/?page_id=4362 。五度697.2が5個、702が7個。

松蔭チャペル https://pianotuning.jp/?page_id=3462 は保留。掲載画像では五度696.5が7個、702が4個、716が1個で、合計8399.5 centとなり閉環に必要な8400 centに0.5不足します。ウルフを716.5へ補正すれば閉じますが、B・F♯の長三度は422→422.5、C♯は416.5→417、A♭は411→411.5となり掲載図の全音程とは一致しません。丸め／誤記の原因は未確認のため無断補正して登録していません。

```

```

平均律、オクターブをまたぐ音程、Kirnberger I、真円条件、400 centの内端、入力検証、成立しない幾何をテストします。

## 色と楕円の更新

完全五度の最新式（cはcent、Lab白色点はD50）:

```
c <= 680: L*=a*=b*=0
680 < c <= 702: L*=100*((c-680)/22)^0.82, a*=b*=0
702 < c: d=min(c,738.5)-702
L*=95.8634 - 1.18098*d - 0.00692859*d²
a*=6.40959 + 0.410919*d + 0.00884569*d²
b*=-0.840578 - 0.157662*d + 0.000665994*d²
```

702 centは白、直後はクロマ約6.464のピンクとなり、境界は不連続です。LabからXYZ(D50)、Bradford順応でXYZ(D65)、線形RGB、sRGBへ変換します。738.5 cent超は未検証の外挿を避け、738.5の色に固定します。SVG保存も同じ配色を使い、metadataに式の識別子と適用範囲を記録します。

真円校正は五度700 centかつ厳密な純正長三度。半径R=1のとき、純正の半軸はa=b=0.205604647。平均律400 centはa=0.25、b=0.189468691（軸比1.31948）。ピタゴラス長三度1200 log2(81/64)=407.820003462 centはa=0.275366401、b=0.179599370（軸比1.53323）。aは半径方向、bは接線方向です。

色の採取元: https://pianotuning.jp/?page_id=1027 、https://pianotuning.jp/?page_id=3956 。長三度はL*・C*を純正長三度と400 centで区分した連続式（直線・四次・四次）、hをシグモイド式で計算。400 cent以上はL*・C*が単調非増加、hが単調増加です。h(c)=91.62802015984734+152.42338423628564/(1+exp(-0.18828126070410406*(c-402.11542070352215)))。L*・C*の全係数はpalette.jsのTHIRD_LCに保存。Labへの変換はa*=C*cos(h)、b*=C*sin(h)（角度をラジアンに変換）。sRGB色域外はRGB成分を0〜1にクリップ。SVGも同じ配色式を使用。長三度384〜428、五度680〜738.5の外側は端の色で固定します。

20ページの主図を比較。例えば392 centの色は基準ページと一部掲載例で赤成分が13異なり、411.5 centもページ2680と1545で色が異なります。統一した音程→色の規則では全例のRGBを同時に再現できません。JPEG圧縮・文字・目盛線による測定の揺れもあります。
